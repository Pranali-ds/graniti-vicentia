🧠 Slide 3: What is SuiteCommerce?

What to say:
SuiteCommerce is a unified eCommerce platform inside NetSuite.

👉 Key idea:
Instead of using separate systems for website, inventory, and orders, everything is connected.

Explain features simply:

Omni-channel experience → same data across website, store, backend
Mobile optimized → works well on phones
Personalization → customers see relevant products
Real-time data → inventory and orders update instantly
Global commerce → supports multiple countries and currencies

👉 One line summary:
“SuiteCommerce connects your online store directly with your business operations.”

⚙️ Slide 5: Benefits & Omni-Commerce Challenges

What to say:
Businesses face problems like:

Managing multiple systems
Different data in different places
Currency and region complexity

SuiteCommerce solves this by:

Providing one single platform (ERP + CRM + eCommerce)
Giving real-time data (inventory, pricing, customers)
Supporting:
Multi-currency
Multi-subsidiary
Centralized order management

👉 Key line:
“It creates a single source of truth for all business data.”

⚖️ Slide 6: SCS vs SCA (Comparison)

What to say:
There are two versions of SuiteCommerce:

🟢 SCS (SuiteCommerce Standard)
Easy to use
Minimal customization
Best for quick setup
🔵 SCA (SuiteCommerce Advanced)
Highly customizable
Requires development (SuiteScript, extensions)
Best for complex business needs

👉 Simple way to explain:

SCS = Plug and play
SCA = Flexible but needs coding

🌐 Slide 10: Web Site Setup & Search Index

What to say:

🔹 Website Setup Record

Controls:

Domain (URL)
Languages
Currency
Cart & checkout

👉 This is the main configuration for your website

🔹 Search Index

This is very important.

👉 What it does:

Scans product data (name, price, category)
Makes search fast and accurate

👉 Important point:
Whenever you update items or categories →
You must regenerate the search index
